*beta2 修复了 beta1 的若干问题，并完善了 Bark*

**仍然不兼容旧版配置。beta1 的配置这次也需要重新配置，做好数据备份**

本版本为预览版，可能有 bug 或功能失效，欢迎提 issue 和 PR

## 新增

- Bark 支持全部参数
- Bark 支持推送加密，可选 AES128/192/256，CBC/ECB/GCM
- Bark 实例页新增指南：如何取密钥、如何配置加密
- 指南支持加粗和链接

## 修复

- **通知没有副标题时，转发的正文为空**（微信等应用的通知都受影响）
- Bark 改用独立的副标题字段，不再把副标题塞进正文
- 关闭加密开关后，仍然发送加密内容
- 自定义服务取名 Custom Service 时，显示成「自定义服务」
- 实例列表拖动排序后，图标不跟随
- 导出再导入会丢失服务自己的字段
- Bark 实例页有两处多余的空白

## 已知问题

- 示例快捷指令的签名将于 2027 年 11 月到期，后续需联网重新签名。服务已内置 HubSign 续签，但中国大陆境内有 Cloudflare 防火墙，有新方法欢迎 PR
