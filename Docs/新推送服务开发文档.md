# Pusher 新推送服务开发文档

> 本文基于当前仓库代码编写，以 `NSPushRequest` 重构后的实现为准。
> 目标读者：想给 Pusher 新增一个内置推送服务的开发者。

---

## 1. 添加一个内置服务，总共要做的事

1. 新建 `Core/Services/NSP<名字>Service.h`。
2. 新建 `Core/Services/NSP<名字>Service.m`。
3. 新建 `Preferences/Resources/<名字>.plist` 设置界面。
4. 构建，`Generated/BuiltinServices.generated.h` 会自动更新。

不需要手工改 Makefile、import 列表或服务名单。

---

## 2. 核心架构

### 2.1 数据流

```
SpringBoard 收到通知
  → BBServer hook (Tweak.xm)
  → NSPusher.handleBulletin:
      全局过滤 / 标题防循环
      → 对每个已启用服务调用 sendToService:
         服务类 +requestForBulletinContext:config:completion:
         返回/回调 NSPushRequest
      → NSPushRequestSender 发送
```

### 2.2 关键文件

| 文件 | 作用 |
| --- | --- |
| `Core/NSPushService.h/.m` | `NSPPushService` 协议、`NSPushServiceBase` 基类、`NSPushServiceManager` 注册表 |
| `Core/NSPushRequest.h/.m` | 请求模型：`urlString`、`headers`、`infoDict`、`logInfoDict`、`method`、`bodyType`、`resendHandler` |
| `Core/NSPushConfig.m` | 读取 prefs，构建 `NSPushServiceConfig`，调用 `urlForEventName:dbName:serverURL:` 生成 URL 模板 |
| `Core/NSPushConfigModels.m` | `NSPushServiceConfig` / `NSPushConfigSnapshot`，`effectiveConfigForAppID:` 合并 per-app 覆盖 |
| `Core/NSPusher.m` | 分发入口 |
| `Core/NSPushRequestSender.m` | GET/HEAD query、其他方法 JSON/form、重试、图片缩小重发、按 `logInfoDict` 记日志 |
| `Core/Services/` | 每个服务一个 `NSP<Xxx>Service.h/.m` |
| `Shared/NSPushPrefsStore.h/.m` | 偏好设置读写 |
| `Shared/NSPushLogStore.h/.m` | 日志读写 |
| `Generated/BuiltinServices.generated.h` | 构建期自动生成的服务 import 和名单 |
| `Preferences/Resources/<服务名>.plist` | 服务设置页 |

### 2.3 注册与名单生成

- 每个内置服务在 `+load` 中调用
  `[NSPushServiceManager registerServiceClass:self forName:[self serviceName]];`。
- `NSPushServiceManager` 查不到名字时返回 `NSPCustomService`。
- `scripts/generate_builtin_services.sh` 扫描 `Core/Services/NSP*Service.h`，
  取每个头文件里**第一个** `#define PUSHER_SERVICE_* @"..."` 宏作为服务名，
  生成 `Generated/BuiltinServices.generated.h`。
- 因此服务名宏必须写在头文件最前面；`_URL`、`_APP_ID` 等变体放在它后面即可。

### 2.4 配置存储

- 内置服务：`BuiltInServices[服务名] = { ... }`
- 自定义服务：`CustomServices[服务名] = { ... }`
- 全局应用列表：`Global[appList]`、`Global[appListIsBlacklist]`
- 其余全局开关（`Enabled`、`WhenToPush`、`WhatNetwork`、SNS 等）仍在顶层。
- per-app 覆盖：`BuiltInServices[服务名][customApps][appID]` 或
  `CustomServices[服务名][customApps][appID]`。

读写统一走 `NSPushPrefsStore`；日志统一走 `NSPushLogStore`。

### 2.5 服务返回什么

服务不再分别返回 URL / header / body，而是返回一个 `NSPushRequest`：

```objc
[NSPushRequest requestWithURLString:@"..."
                            headers:@{...}
                           infoDict:@{...}]
// 或指定 method
[NSPushRequest requestWithURLString:@"..."
                            headers:@{...}
                           infoDict:@{...}
                             method:@"GET"]
```

服务负责在 `requestForBulletinContext:config:` 里完整设置 `method`（默认
`POST`）、`bodyType`（默认 `json`，可设为 `form`）以及 `logInfoDict`。
`NSPusher` / `NSPushRequestSender` 不再覆盖或改写请求，只按服务返回的原样发送。

## 3. 最小示例：Bark

### 3.1 头文件

```objc
#import "../NSPushService.h"
#import <Foundation/Foundation.h>

#define PUSHER_SERVICE_BARK @"Bark"
#define PUSHER_SERVICE_BARK_URL @"https://api.day.app/REPLACE_KEY"

@interface NSPBarkService : NSPushServiceBase
@end
```

### 3.2 实现文件

```objc
#import "NSPBarkService.h"
#import "../../helpers.h"
#import "../NSPushConfig.h"
#import "../NSPushSupport.h"

@implementation NSPBarkService

+ (void)load {
  [NSPushServiceManager registerServiceClass:self forName:[self serviceName]];
}

+ (NSString*)serviceName {
  return PUSHER_SERVICE_BARK;
}

+ (NSString*)urlForEventName:(NSString*)eventName
                      dbName:(NSString*)dbName
                   serverURL:(NSString*)serverURL {
  NSString* finalURL = nil;
  if (serverURL && serverURL.length > 0) {
    if ([serverURL hasSuffix:@"/"]) {
      finalURL = [serverURL stringByAppendingString:@"REPLACE_KEY"];
    } else {
      finalURL = [serverURL stringByAppendingFormat:@"/REPLACE_KEY"];
    }
  } else {
    finalURL = PUSHER_SERVICE_BARK_URL;
  }
  return finalURL;
}

+ (NSPushRequest*)requestForBulletinContext:(NSPBulletinContext*)context
                                     config:(NSPushServiceConfig*)config {
  return [NSPushRequest requestWithURLString:[self replacedKeyURLStringForConfig:config]
                                     headers:nil
                                    infoDict:@{
                                      @"title" : context.title ?: @"",
                                      @"body" : context.message ?: @""
                                    }];
}

+ (NSDictionary*)extraPrefsForName:(NSString*)name
                      servicePrefs:(NSDictionary*)servicePrefs {
  return @{
    @"serverURL" : XStrDefault(servicePrefs[NSPPreferenceServiceServerURLKey],
                               @"https://api.day.app")
  };
}

@end
```

### 3.3 关键点

- `replacedKeyURLStringForConfig:` 是基类 helper：
  用 `config.rawPrefs[@"key"]` 替换 `config.rawPrefs[@"url"]` 中的 `REPLACE_KEY`。
- `urlForEventName:dbName:serverURL:` 在配置加载阶段生成 URL 模板，存到
  `config.rawPrefs[@"url"]`。
- 没有实现异步 `requestForBulletinContext:config:completion:`，基类会自动包一层调用同步版。

### 3.4 设置界面

`Preferences/Resources/Bark.plist` 的 `service` 字段必须等于 `Bark`，输入框的 `key`
就是 `BuiltInServices[Bark][key]` 的字段名。普通输入框的读写由 `NSPServiceController`
转发到 `NSPSharedSpecifiers`，最终写入嵌套存储。

## 4. 进阶示例：企业微信（异步请求 + 每应用覆盖）

### 4.1 头文件

```objc
#import "../NSPushService.h"
#import <Foundation/Foundation.h>

#define PUSHER_SERVICE_WECHAT @"Wechat"
#define PUSHER_SERVICE_WECHAT_URL                                              \
  @"https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token="            \
  @"REPLACE_DYNAMIC_KEY"

@interface NSPWechatService : NSPushServiceBase
@end
```

### 4.2 服务特有字段

```objc
+ (NSDictionary*)extraPrefsForName:(NSString*)name
                      servicePrefs:(NSDictionary*)servicePrefs {
  return @{
    @"corpid" : XStrDefault(servicePrefs[NSPPreferenceServiceCorpidKey], @""),
    @"corpsecret" :
        XStrDefault(servicePrefs[NSPPreferenceServiceCorpsecretKey], @""),
    @"agentID" : @(NSPushIntegerValue(
        servicePrefs[NSPPreferenceServiceAgentIDKey], 0)),
    @"touser" : XStrDefault(servicePrefs[NSPPreferenceServiceTouserKey], @"")
  };
}

+ (NSDictionary*)extraCustomAppPrefsForName:(NSString*)name
                                   appPrefs:(NSDictionary*)appPrefs {
  return @{@"touser" : XStrDefault(appPrefs[@"touser"], @"")};
}
```

### 4.3 异步请求

企业微信需要先获取 `access_token`，所以覆写异步方法：

```objc
+ (void)requestForBulletinContext:(NSPBulletinContext*)context
                           config:(NSPushServiceConfig*)config
                       completion:(void (^)(NSPushRequest* request))completion {
  // 组装 body：agentid 必须是整数
  NSString* touser = XStrDefault(config.rawPrefs[@"touser"], @"");
  NSInteger agentIDValue = NSPushIntegerValue(config.rawPrefs[@"agentID"], 0);
  NSDictionary* infoDict = @{
    @"touser" : (touser.length != 0) ? touser : @"@all",
    @"msgtype" : @"text",
    @"agentid" : @(agentIDValue),
    @"text" : @{
      @"content" : XStr(@"%@\n%@", context.title ?: @"", context.message ?: @"")
    },
    @"safe" : @0
  };

  NSString* corpid = XStrDefault(config.rawPrefs[@"corpid"], @"");
  NSString* corpsecret = XStrDefault(config.rawPrefs[@"corpsecret"], @"");
  if (corpid.length == 0 || corpsecret.length == 0) {
    if (completion) completion(nil);
    return;
  }

  // 先查缓存；缓存 key = corpid|corpsecret
  NSString* cacheKey = [NSString stringWithFormat:@"%@|%@", corpid, corpsecret];
  BOOL cacheHit = NO;
  NSString* cachedToken = cachedWechatTokenForKey(cacheKey, &cacheHit);
  if (cacheHit) {
    if (completion) {
      completion([NSPushRequest
          requestWithURLString:[[PUSHER_SERVICE_WECHAT_URL
              stringByReplacingOccurrencesOfString:@"REPLACE_DYNAMIC_KEY"
                                        withString:cachedToken] copy]
                       headers:nil
                      infoDict:infoDict]);
    }
    return;
  }

  // 请求 gettoken；当前实现用 POST，参数走 query
  NSString* reqUrl = @"https://qyapi.weixin.qq.com/cgi-bin/gettoken";
  NSDictionary* params = @{@"corpid" : corpid, @"corpsecret" : corpsecret};
  NSMutableArray* queryItems = [NSMutableArray array];
  NSCharacterSet* allowed = [NSCharacterSet
      characterSetWithCharactersInString:@"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghij"
                                         @"klmnopqrstuvwxyz0123456789-._~"];
  for (NSString* key in params) {
    NSString* encoded = [(NSString*)params[key]
        stringByAddingPercentEncodingWithAllowedCharacters:allowed];
    [queryItems addObject:[NSString stringWithFormat:@"%@=%@", key, encoded]];
  }
  reqUrl = [reqUrl stringByAppendingFormat:@"?%@",
                                          [queryItems componentsJoinedByString:@"&"]];
  NSMutableURLRequest* request =
      [NSMutableURLRequest requestWithURL:[NSURL URLWithString:reqUrl]];
  [request setHTTPMethod:@"POST"];
  [request setValue:@"application/json" forHTTPHeaderField:@"Accept"];

  [[[NSURLSession sharedSession]
      dataTaskWithRequest:request
        completionHandler:^(NSData* data, NSURLResponse* response,
                            NSError* error) {
          NSString* token = @"";
          if (!error) {
            id jsonResponse =
                [NSJSONSerialization JSONObjectWithData:data options:0 error:nil];
            if ([jsonResponse isKindOfClass:NSDictionary.class] &&
                [jsonResponse[@"errcode"] isEqual:@(0)]) {
              id accessToken = jsonResponse[@"access_token"];
              if ([accessToken isKindOfClass:NSString.class]) {
                token = (NSString*)accessToken;
              }
            }
          }
          if (token.length > 0) {
            cacheWechatTokenForKey(cacheKey, token);
          }
          if (completion) {
            if (token.length == 0) {
              completion(nil); // 失败：让上层跳过发送
              return;
            }
            completion([NSPushRequest
                requestWithURLString:[[PUSHER_SERVICE_WECHAT_URL
                    stringByReplacingOccurrencesOfString:@"REPLACE_DYNAMIC_KEY"
                                              withString:token] copy]
                             headers:nil
                            infoDict:infoDict]);
          }
        }] resume];
}
```

token 缓存必须用文件级 static，否则读和写会各持有一份字典，缓存永远不命中。

`NSPushRequest` 支持 `resendHandler`：每次发送收到响应后，Sender 会回调服务；服务可以检查
响应内容（例如企业微信 `errcode` 40014/42001 表示 access_token 失效），刷新 token 后通过
`completion(newRequest, NO)` 返回新请求，主框架会自动重新发送。`completion(nil, NO)`
继续走默认处理；`completion(nil, YES)` 停止并记为失败。

### 4.4 每应用覆盖

- 服务类：`extraCustomAppPrefsForName:appPrefs:` 返回 `touser`。
- Preferences：在 `NSPSharedSpecifiers get:withAppID:isCustomService:` 中给 Wechat
  加分支，返回 `[NSPSharedSpecifiers wechat:appID]`。
- plist：`Wechat.plist` 加 `App Customization` 入口，`defaultTouserKey` 指向 `touser`。
- `touser` 输入框由 `NSPSharedSpecifiers+ServiceBuilders` 动态生成，不写在 plist 里。

## 5. 协议方法速查表

| 方法 | 是否必须 | 基类默认 | 说明 |
| --- | --- | --- | --- |
| `+serviceName` | 必须 | nil | 注册名，和宏、plist 文件名一致 |
| `+requestForBulletinContext:config:completion:` | 二选一 | 调用同步版 | 异步构建请求；失败回调 nil |
| `+requestForBulletinContext:config:` | 二选一 | 抛异常 | 同步构建 `NSPushRequest` |
| `+extraPrefsForName:servicePrefs:` | 可选 | `@{}` | 服务特有字段默认值 |
| `+extraCustomAppPrefsForName:appPrefs:` | 可选 | `@{}` | per-app 覆盖字段 |
| `+urlForEventName:dbName:serverURL:` | 可选 | `@""` | 生成 URL 模板 |
| `+shouldIncludeIconForConfig:` | 可选 | NO | 是否在共享 data dict 中加图标 |
| `+shouldIncludeImageForConfig:` | 可选 | NO | 是否在共享 data dict 中加图片 |
| `+replacedKeyURLStringForConfig:` | helper | 替换 `REPLACE_KEY` | 用 `key` 替换 URL 模板占位符 |
| `+baseInfoDictForBulletinContext:config:` | helper | 共享 data dict | 生成通用字段 + 可选 icon/image |
| `+logInfoDictForInfoDict:` | helper | 复制并替换大字段 | 生成日志安全的请求体 |

---

## 6. 注意事项

- `NSPushRequestSender` 支持 GET/HEAD query，其他方法支持 JSON 或 form 表单（`application/x-www-form-urlencoded`）。
- 服务必须设置 `logInfoDict`（可用 `logInfoDictForInfoDict:` 生成），主框架不会重写日志体。
- `devices` 是字典数组；`sounds` 在 `NSPushConfig` 加载后是已启用声音 ID 的字符串数组。
- 新增服务后记得在 `Preferences/Resources/zh-Hans.lproj/Localizable.strings`
  加显示名。
- 不要直接修改 `Generated/BuiltinServices.generated.h`，它是构建期生成的。

## 7. 检查清单

- [ ] 服务名宏是头文件里第一个 `PUSHER_SERVICE_* @"..."` 宏
- [ ] `serviceName`、宏、plist 文件名一致
- [ ] 实现了 `+requestForBulletinContext:config:` 或异步版
- [ ] 需要 per-app 覆盖的服务实现了 `extraCustomAppPrefsForName:` 并在 `NSPSharedSpecifiers` 注册
- [ ] plist 字段与 `config.rawPrefs[@"..."]` 一致
- [ ] `make clean package THEOS_PACKAGE_SCHEME=rootless` 编译通过
