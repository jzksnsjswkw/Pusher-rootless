# Pusher 3.0.0 beta 1

*v3，使用 Swift 完全重写，全新架构带来更强的性能、更丰富的功能*

**不再兼容旧版配置，升级后所有服务需要重新配置，做好数据备份**

本版本为预览版，可能有 bug 或功能失效，欢迎提 issue 和 PR

## 新功能

- 同服务可多次添加，例如添加两个 bark，配置独立的 key
- 新增自定义服务，可用 JavaScript 编写自定义服务，并添加独有的配置项
- 每个实例新增两个 JavaScript Hook：一个在收到通知时触发，一个在应用和设备筛选之后触发，可以改写或丢弃特定通知
- 新增快捷指令，通知内容会作为词典传入，在后台静默运行
- 新增导入及导出功能

## 已知问题

- 示例快捷指令的签名将于 2027 年 11 月到期，后续需联网重新签名。服务已内置 HubSign 续签，但中国大陆境内有 Cloudflare 防火墙，有新方法欢迎 PR
